\# PathFinder AI - Claude Code Instructions



\## Project Goal



Build a capstone prototype called PathFinder AI.



PathFinder AI is a memory-enabled, conversational AI counselor for high school students, parents, and school counselors.



The system helps students:

\- Discover careers they may not know exist

\- Understand majors connected to those careers

\- Explore college pathways

\- Use GPA or academic profile for realistic guidance

\- Build a personalized next-step roadmap

\- Continue conversations using memory



\## Target Users



Primary:

\- High school students applying to colleges

\- High school students unsure about careers or majors



Secondary:

\- Parents

\- School counselors



\## MVP Scope



Build only the first version.



Included:

\- Chat-based discovery experience

\- Student profile extraction

\- Career recommendations

\- Major recommendations

\- Basic GPA-aware college guidance

\- Persistent memory using SQLite

\- Curated knowledge base using local files

\- Simple Streamlit UI

\- Basic evaluation checks



Not included:

\- Scholarship engine

\- Parent portal

\- Counselor dashboard

\- Real-time college APIs

\- SAT/ACT prediction

\- Application tracking

\- Resume builder



\## Preferred Tech Stack



\- Python

\- Streamlit

\- SQLite

\- Local JSON/Markdown data files

\- Pydantic schemas

\- Optional LangGraph later

\- Keep the implementation simple and easy to complete for a 1-2 week capstone



\## Development Rule



Do not create a large complex system immediately.



First:

1\. Create a clean project structure

2\. Create documentation files

3\. Create a simple Streamlit prototype

4\. Add memory

5\. Add career data

6\. Add recommendation logic

7\. Add evaluation checks



Prefer small working increments over large generated code.
