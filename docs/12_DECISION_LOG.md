# PathFinder AI — Decision Log

## Purpose

Track major architecture and product decisions. When a question arises about why something was built a certain way, or whether an alternative should be revisited, check here first.

## How to Add Future Decisions

When a significant architecture or product decision is made, add a row to the table above using this format:

```
| D012 | [Decision title — one clear sentence] | Approved / Proposed / Rejected | [Why this choice was made] | [What else was considered] | [What changes as a result] |
```

**When to add a decision:**
- A technology or library is locked in or swapped
- A scope boundary is changed (in-scope / out-of-scope)
- An agent responsibility is significantly redefined
- A model or cost policy is changed
- A data schema or storage strategy is updated

**When not to add a decision:**
- Implementation details that don't affect other layers
- Bug fixes
- Documentation formatting changes
